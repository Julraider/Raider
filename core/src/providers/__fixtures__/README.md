# Provider-Fixtures

Aufgezeichnete Anbieterantworten, gegen die die Adapter getestet werden.

**`anthropic-message.json` ist aktuell ein Platzhalter** in der dokumentierten
Antwortstruktur der Anthropic Messages-API — noch keine echte Aufzeichnung,
weil beim Bau von Schritt 2 kein API-Key vorlag.

Laut CLAUDE.md sollen Adapter gegen **echte, aufgezeichnete** Antworten gebaut
werden. Sobald ein echter Modellaufruf läuft, wird dieses Fixture durch eine
echte Antwort ersetzt.
